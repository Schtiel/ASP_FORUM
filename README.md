# ASP Forum

Este proyecto está diseñado para **aprender y experimentar con ASP.NET**, explorando cómo funcionan sus componentes, la arquitectura de aplicaciones web, y comparando con otros frameworks de .NET.  
El objetivo es practicar buenas prácticas, seguridad, manejo de datos y desarrollo full-stack en un entorno controlado.  
Aunque ya cuento con amplia experiencia en .NET, este proyecto me permitirá **profundizar en ASP.NET, WebForms, MVC, SignalR, APIs REST y la integración con SQL Server**, así como en despliegue local con **Docker**.

#### Objetivos

- [ ] Conexión a SQL Server
- [ ] Creación de modelos y DTOs para la base de datos
- [ ] Registro de usuarios
  - [ ] Validación de datos
  - [ ] Hash y salt de contraseñas
- [ ] Login de usuarios
  - [ ] Gestión de sesiones seguras (SID + verificación de User-Agent)
- [ ] Logs de usuario (login, registro, acciones importantes)
- [ ] Chat en vivo con SignalR
  - [ ] Implementación de ChatBox en el portal
- [ ] Panel de Usuario para editar propiedades
  - [ ] Foto de perfil
  - [ ] País
  - [ ] Edad
  - [ ] Firma en foro
- [ ] Sistema de foro completo
  - [ ] Categorías
  - [ ] Subcategorías
  - [ ] Crear tema
  - [ ] Ver tema
  - [ ] Editar / Borrar tema
  - [ ] Enviar respuesta
  - [ ] Editar / Borrar respuesta
  - [ ] Opciones de moderación
  - [ ] Paginación de respuestas
- [ ] APIs REST para portal y foro
- [ ] Seguridad en APIs
  - [ ] Autenticación
  - [ ] Autorización
- [ ] Integración con herramientas de desarrollo
  - [ ] Git
  - [ ] Swagger / Postman
- [ ] Arquitectura de proyecto
  - [ ] Clean Architecture
  - [ ] CQRS
- [ ] Configuración de Dockerfile para despliegue local del proyecto
